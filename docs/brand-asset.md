## Acceptance criteria

The approved asset presents the words **THINKING COMPUTER** as the central, dominant, highly legible white pixel wordmark. It uses a near-black background with subdued gray terminal noise, binary texture, and low-contrast neural/circuit-like paths pushed behind the title. It contains no hands, robots, faces, brain icon, foreground nodes, or secondary labels.

The asset is an original image generated for this project. The provided reference informed only the restrained monochrome terminal mood; its composition, text, and elements were not reproduced.
